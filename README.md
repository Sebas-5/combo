# combo

Tu grupo propone, vota y decide. PWA (React + Vite + Firebase) para que grupos de amigos organicen planes en un solo sitio. Proyecto Intermodular de 2º DAM.

## Arrancar en local

```bash
npm install
cp .env.example .env.local   # y rellena las claves de Firebase
npm run dev
```

(El README completo —Firebase, despliegue e instalación de la PWA— se escribe en el último paso.)
